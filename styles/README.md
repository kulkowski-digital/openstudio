# Style społeczności

Styl to zapisany „przepis na wygląd”: paleta, opis złożony z chipów, czego unikać i siła działania.
Pliki `.styl.json` z tego katalogu można wczytać w aplikacji (**style → wczytaj plik**) i od razu użyć.

## Jak dodać swój

1. Zbuduj styl w aplikacji i kliknij **pobierz plik**.
2. Wrzuć plik tutaj jako `nazwa.styl.json`.
3. W pull requeście napisz jednym zdaniem, do czego ten styl się nadaje, i dołącz 2–3 przykładowe obrazy.

Plik eksportu **nie zawiera** referencji ani identyfikatorów — referencje są lokalne, na Twoim dysku.
Nie wrzucaj tu stylów opisujących konkretnego żyjącego artystę („w stylu X”) — chodzi o klimat, nie o podszywanie się.
